**Choices the brief did not dictate**
- **Seed = 64 bits as two uint32 halves**, text form `7F3A-91C2-0B4D-E6A8`. Algorithm: two multiply-xor-rotate lanes over
  the key's UTF-16 units, started from the parent's halves, cross-mixed finalizer. Probe: bit balance 0.492–0.507,
  avalanche mean 32.0/64 for a flipped parent bit and for key `i`→`i+1`, 100,000-deep chain without a repeat. The raw
  draw is private — a caller can only branch and use a helper. Three literals pin the algorithm.
- **Project references are composite** (declarations to `node_modules/.tmp`), because TS6307 only fires for a composite
  project; plus `noEmitOnError` (without it a wall violation dropped a stray `.d.ts` into `src/` — lesson logged).
- **Lint is stricter than asked:** the engine may import only `./…` or `#engine/…` (so packages are banned too);
  `../` imports are banned everywhere (aliases `#engine/ #ui/ #platform/ #content/ #tests/`); `unsafeHTML`, `outerHTML`,
  `insertAdjacentHTML`, `new Date` in the engine; a 20-line local rule enforces file = class name and no `index.ts`.
- **Content fork, one rule:** every directory with lists has an `index.txt` whose entries are its file stems. So
  `names/buildings/<culture>_{adj,noun}.txt` became `names/buildings/{adj,noun}/<culture>.txt` (index copied into
  both), and `themes/index.txt` (`conditions`) and `themes/doors/index.txt` were added. 79 files hash-identical to
  the Groovy copy at fork time, 81 in all. Missing or empty list = error, never a silent default.
- **Universe name** borrows the building adjective/noun lists of one culture ("Hollow Void") until I02 brings the real one.
- **Fonts are bundled** (`@fontsource`, latin subsets) instead of the mock's Google Fonts link: no third-party
  request, works offline, and the browser test can assert "no failed request".
- `toViewModel` is a method of `TitlePresenter` (principle 2: no free static logic), injected into `Shell` as a function.
- Key hints (`[N]`, `[R]`) are hidden on coarse pointers; buttons are 48 px high, 56 px on touch.
- `localStorage` is handed over as a getter — with site data blocked, reading `window.localStorage` itself throws.
- `npm run check` runs every step even after a failure and prints the failed step's output above the line; zero
  tests counts as FAIL.
- My slip: a stray `git checkout HEAD~1 --` detached HEAD for one command; returned to the branch at once, nothing lost.

## Part C — Review fixes + publishing

**Fixes** (tests first; one commit per group)
1. **Focus** — `Shell` owns the rule for every screen: if a render removes the element that held the focus, the first
   option button takes it; focus outside the screen (or nowhere — a bare `N` key) is never taken. `e2e/focus.spec.ts`.
2. **Unguarded platform/ui** — `e2e/resilience.spec.ts`: `localStorage` getter throws, `setItem` throws, four corrupt or
   foreign saved values → fresh game, a tap on a stale / unknown / empty `data-option` → ignored; no console errors.
   The stale tap is stopped twice (router, then `GameEngine.step`), so removing only the router's check stays green.
3. **Cultures, one owner** — `themes/cultures/index.txt`. The three copies are deleted (`names/buildings/adj`, `…/noun`
   and a fourth the review did not list, `themes/atmosphere/walls`); those directories are "keyed by culture" and
   `BundledContent.test.ts` asserts their files equal the index and that no other index repeats it (81 → 78 files).
   `UniverseNamer` = `nameIn(cultureOf(seed), seed)`; `UniverseNames.test.ts` iterates the index.
4. **Title words, one owner** — stage line, `UNIVERSE` / `SEED`, region names (aria) and the build stamp are in `TitleVM`;
   `ViewsCarryNoWords.test.ts` scans every `*View.ts` for literal text and literal `aria-label`.
5. **Lint wall** — any `..` segment in an import; in the engine the globals `Date`, `performance`, `globalThis`, `window`,
   `self`, `global` are restricted and `Date()` as a call is banned.
6. **e2e base** — derived from `baseURL`; the test now also asserts every request stays under it.
7. **Seed keys** — helpers draw from `#range` / `#pick` / `#probability`; a number key `n` is the text `#n:<n>`, so
   `branch(1)` ≠ `branch('1')`; `branch` refuses text keys starting with `#` and number keys that are not whole.
8. **Stale paths** — `docs/README.md` (7 links), `tasks/todo.md`, the cheat sheet's launch line, root

**Publishing — the choice and why.** The GitHub login on this machine has no `workflow` scope, so a workflow file cannot
be pushed; a human can later run `gh auth refresh -s workflow` to allow an Action. Until then the site stays Pages
"legacy" mode (Jekyll builds `master:/docs`) and the game is **committed** into `docs/play/` by `npm run publish:site`
(`web/scripts/publish.ts`): check green → build with the production base → refuse names Jekyll drops (leading `_ . #`,
trailing `~`) → empty `docs/play/` → copy `dist/**` → `build.txt`. `docs/_config.yml` `exclude` does not hide `play/`,
there is no `include`, and no `.nojekyll` was added. The title screen shows `build <stamp>` (Vite `define` ← `ET_BUILD`
← the script; `dev` otherwise) — `main.ts` hands it to `TitlePresenter`; the engine never sees it. `docs/index.md`
links to `/play/`. A merge to `master` + push is what makes a published build live.

**Choices the brief did not dictate**
- **The stamp is the last commit that touched `web/`, not HEAD**, and the script refuses a dirty `web/`. Reason: the
  publish commit touches only `docs/play/`, so with HEAD the stamp (and the JS file name that embeds it) would change on
  every re-run. Observed: published at `18c0355`, committed (HEAD moved), ran again → `BUILD=18c0355`, `git status
  --short` empty. As the brief expected, the stamp names the commit *before* the publish commit — the source it was built from.
- Number keys must be safe integers (`branch(1.5)` throws); `-0` is `0`.
- Banning the global `Date` outright (not only `Date()`) also closes `const D = Date`.
- Playwright: `workers: 3`, `timeout: 60 s`. With the default 6 workers / 30 s, unrelated tests timed out under load on
  this machine (twice); now the 36 tests take ~35 s. No retries — they would hide a real flake.
- `tasks/PORT_QUEUE.md` I01 row: "one Action builds…" replaced by the publish-script wording (the fact became false).
  `tasks/RECOVERY_PROMPT.md` untouched: nothing in it became false (974 words).
- `docs/index.md` "Last updated" line refreshed with the link.
