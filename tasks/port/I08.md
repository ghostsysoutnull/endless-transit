## Guide-vs-code disagreements (Decision 6) and the defects fixed (Decision 7)

1. **The legend described glyphs never drawn** (HK-023, HOUSEKEEPING.md:48; TelemetryComponent.groovy:82 `■ Node | ░ Void`):
   the legend is built from the grid's own glyphs (`YOU` with the origin's, `VISITED`/`UNVISITED` with the
   children's, `GLITCH` with `X` only when marks exist) and drawn on the canvas, in the same inks.
2. **The `X` marker never appeared as `X`** (HK-023, HOUSEKEEPING.md:49; `glitchText("X", 1.0, r)`): it is an `X`.
3. **Map colours printed as words** (HK-023, HOUSEKEEPING.md:53): the canvas reads the stylesheet's tokens; the
   nodes take the map's `--frame` (the place's colour; the void's below the bedrock). A solar system's planets are
   *not* each inked in their own frame — one owner of hues (the stylesheet) over Container.groovy:42-48.
4. **The `m` at an elevator**: the old floor plotted its `children` (the corridor); here a floor's map is its doors
   in either mode (`Floor.mapNodes`), so MAP at the elevator shows the strata's rooms rather than one node.
5. **`ll` has no key** (Guide:92 names two letters; keys are one): TRACE is a button, keyless on the desktop too.
6. **The universe and filament pane variants** (TelemetryComponent.groovy:86-125, decorative) are not ported: every
   level draws the same local lattice of its children.
7. **`p`/`P` screenshots** (Guide:93) are not ported: no file system in the browser.

## Choices the brief did not dictate

- **The dock folds after four** (LEAVE, SCAN, MAP, BUFFER; then MORE → TRACE, TITLE SCREEN, END SESSION), on both
  profiles, as a toggle of the view (no engine option, no `data-option`); it survives a render and the trip to the
  title, so Enter's round trip finds its button. Every dock option stays in the router's list, so a key works while
  folded. I09 polishes.
- **Canvas approach**: pictures are pure functions of plain data; `CanvasView` owns the DOM (`ResizeObserver`,
  DPR ≤ 2, `getComputedStyle` for the tokens, one `requestAnimationFrame` loop per canvas for the pulse, none under
  reduced motion). Three canvases at most: the pane map, the MAP panel, the TRACE panel. Text ≥ 12 px everywhere.
- **The accessible alternative**: the canvas host is `role="img"` named by the presenter's summary (`Lattice map of
  Bright Boulevard: 4 nodes, 0 visited.`); every node / level is a `.vh` list item.
- **Words:** `NEURAL_LATTICE_PROJECTION: n nodes plotted from <place>.`, `SCAN_ERROR: Current location does not
  support spatial projection.`, `NEURAL_LATTICE_TRACE_INITIATED: n levels from the universe.`, the headings
  `[NEURAL_LATTICE_PROJECTION]`, `[NEURAL_MAP: <KIND>]`, `[NEURAL_LATTICE_TRACE_INITIATED]`, `SCAN_ORIGIN: <place>`.
- **`m` is claimed**: the child pool loses it (Broad Alley's 20th building has no key now).
