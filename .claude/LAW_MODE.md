# Law mode

A session that works on the rules themselves, not the product. It runs only when the user says "law mode".

1. **Target.** I read the rules the user names with what refers to them and what they refer to.
2. **Research what is general.** A general principle is checked against the people who first stated it and the sources
   that refined it; the sources are cited in chat, the file keeps only the rule.
3. **Assess.** What I look for: history inside a rule; an example that will go stale or narrow the rule; a fact with
   two owners; a rule doing two jobs; a rule contradicting another rule or the code; a rule nothing guards.
4. **Limits.** Only rules and docs change, never the product or its tests; a subagent, when there is one, is
   read-only.
5. **Moves lose nothing.** A rule moved to another file is checked by script against its old text.
6. **Where a rule lives.** The more general a rule, the wider the place that loads it: the most general carry no
   example and no history; the specific live closer to what they govern; detail lives in docs read on demand.

Everything in the Codex still holds, under the user block at the top of `CLAUDE.md`.
