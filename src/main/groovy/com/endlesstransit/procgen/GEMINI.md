# Procedural Generation - Development Context

## Naming
- Use `NameGenerator` for all thematic naming across all scales (from Universes to Streets).
- Maintain naming stability: names should be derived from stable seeds or hierarchical context.

## Gematria (Numeric Frequencies)
- **Logic**: Frequencies are calculated using the "Breathless Abjad" system (ignoring vowels).
- **Resonance**: Master Numbers (11, 22, 33) in the sum are "Resonant" and result in doubled values.
- **Cultural Bonus**: Objects found in rooms matching the planet's `Primary Culture` receive a **+10% Frequency Bonus**.
- **Depth Multiplier**: Frequencies are amplified by the observer's depth in the hierarchy.

## Object Synthesis
- **Themes**: Objects are generated by combining `Culture` assets (the "Body") and `Timeline` assets (the "Time Marker").
- **Hybridization**: Use `ThemeManager.generateHybridObject(culture, timeline)` for consistent procedural flavor.
