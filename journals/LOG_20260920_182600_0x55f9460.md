> Substrate cannot be walked back.* A warning is what a bug looks like once it has been given a voice.

> Layer again, and every Layer above it, always in the same order — so the address means the same thing whoever
> asks, and whenever. And a trace that points somewhere the web truly cannot reach is turned away at the door,
> whole, the way a corrupted one always was.
