## 🌌 THE NARRATIVE (The Vibe)

> The substrate had two instruments: one that asked whether the lattice would compile, one that asked whether the pulse still matched every pinned frame. Neither asked whether the code kept its own promises. The promises lived in retros and lessons — "no static singletons", "never `instanceof` a state", "the model never touches the journal" — and every one of them was enforced by a hand-typed grep, run when someone remembered.
>
> Eighty-three dead imports had settled in the model classes like dust on a console nobody wipes. Fourteen location types still imported a name generator and a gematria engine they had stopped calling months ago. A `Random` was drawn in the universe map and never read. `Player`, the one aggregate every event passes through, was the only production class the type checker never looked at.
>
> The original plan reached for Gradle. The runner has never spoken Gradle; a plugin there would have watched an empty road. So the third instrument was built where the other two live — in `vinc.sh`, on the same classpath convention, one command, one line back.
>
> It shipped green. Not because the debt was gone, but because the debt was *named*: a hundred entries in a baseline file, each one a fact the gate agreed to tolerate for now. Then twelve commits paid it down, five files at a time, and the file could only ever shrink. What remains are nine methods that grew past fifty lines — recorded with their exact length, so the first hand that touches one will hear about it.
>
> The invariants are no longer tribal. A singleton, an `instanceof` on a state, a journal import in the model, a `new Random()` in a HUD component — each is now a rule that fires in six seconds and names the line. The substrate remembers its own laws.
