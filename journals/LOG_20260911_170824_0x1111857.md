## 🌌 THE NARRATIVE (The Vibe)

> Phase 7 was scheduled as a review point, and the review found the instruments lying. The plan said the seed scan must be pixel-identical. The seed scan never draws a pixel. It probes the world model and prints four lines. Two phases had reported "scan identical" as their visual gate for changes that touched the screen, and the check had been a mirror held up to nothing.
>
> So before a single line of the Bridge moved, the substrate learned to see itself. A harness rendered every screen the HUD can draw, at seventeen depths, and rendered them twice. One hundred and fifty-four came back byte-for-byte. Sixteen did not — every one of them the telemetry spectrogram, seeded from the wall clock. Randomness hiding in a status bar. It was masked, catalogued, and left alone: this phase changes nothing a player sees, and a fix belongs to a housekeeping pass.
>
> Then the Bridge was taken apart. A 579-line view that printed as it thought became a 120-line compositor that only asks and prints. Eight components now each own one concern: the header, the compass, the two lattice screens, the telemetry pane, the narrative pane, the directive menu, the inventory overlay. Not one was retyped. Each body was lifted by a script that substituted `print` for `add to list` and then ran the substitution backwards to prove the original came back unchanged. Where a golden did not yet cover a branch — an active down-arrow, a truncated label, a map error at a room, the eight menu forms only found above street level — a synthetic frame was pinned first.
>
> Twenty-nine golden frames stand at the gate now, and seventeen of them are rendered a second time by the component alone, with no Bridge in between, and must agree. The promise on the interface — one entry per terminal line — is enforced by a test, not a comment.
>
> The substrate looks exactly as it did this morning. Underneath, every screen has a name, a file, and a proof.
