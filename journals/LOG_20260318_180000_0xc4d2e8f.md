## Key Lesson
**Rename reveals hidden coupling.** `VibeRegressionTest` had an implicit dependency on
test execution order to initialise `ModelOutput.fmt`. It passed for its entire existence
only because a test with an earlier class name happened to run first. The rename changed
that order and made the dependency visible. Renames are cheap structural probes.
